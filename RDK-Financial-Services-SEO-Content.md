## 6. On-Page SEO Checklist

- [ ] Title tags under 60 characters, unique per page
- [ ] Meta descriptions under 155 characters, unique per page
- [ ] One H1 per page, keyword-aligned but natural
- [ ] H2s for each loan product / service area
- [ ] Image alt text includes location + loan type where relevant (e.g., "personal loan agent Coimbatore")
- [ ] Internal links between homepage and both city landing pages
- [ ] Schema markup (FinancialService) added site-wide
- [ ] Google Business Profile listings created/verified for both Coimbatore and Tirupur (if a Coimbatore office/service point exists)
- [ ] Privacy Policy, Terms of Service, and Loan Disclaimer pages published (required — not yet provided by client)
- [ ] Tamil-language keyword variants added for bilingual pages
- [ ] Mobile page speed optimized (loan calculators/forms should not slow load time)
- [ ] SSR or static pre-rendering enabled so Google indexes full content, not JS shell

## 8. Brand Identity (from client logo)

| Color | Hex (approx.) | Use |
|---|---|---|
| White | `#FFFFFF` | Page background |
| Navy Blue | `#1B2A6B` | Primary brand color — headings, nav, key CTAs |
| Red | `#E52421` | Accent — highlights, hover states |
| Orange | `#F7941D` | Accent — secondary CTAs, icons |
| Yellow | `#FDC70C` | Accent — small highlights, badges |
| Black | `#000000` | Body text / wordmark |

**Design notes:**
- White background confirmed by client — keep the site clean/light to let the logo's colorful swoosh stand out.
- Use navy as the dominant text/nav color (matches the "R" in logo) rather than black, for brand consistency.
- Red/orange/yellow work well as a gradient accent (e.g., section dividers, buttons) echoing the logo's swoosh — avoid using all three flatly side by side, as it can look busy; a gradient or single-accent-per-section approach will read more premium.
- Logo alt text for SEO: `RDK Financial Services logo` (add "loan agent Coimbatore Tirupur" only in surrounding image context, not stuffed into alt text itself).
